# Python_StudentManagement_Project
# Student Management System

## About the Project
A simple Student Management System developed using Python and MySQL to manage student records efficiently through a menu-driven application.

## Technologies Used
- Python
- MySQL
- MySQL Connector

## Features
- Add new student records
- View all student records
- Update existing student details
- Delete student records
- Store and retrieve data using MySQL

## Database
Database Name: `student_db`

Table Name: `students`

## How to Run
1. Install Python and MySQL.
2. Install MySQL Connector:
   `pip install mysql-connector-python`
3. Create the database and required table.
4. Configure your MySQL connection credentials.
5. Run the Python file.

## Learning Outcomes
- Python programming and functions
- MySQL database connectivity
- CRUD operations
- SQL query execution using Python
